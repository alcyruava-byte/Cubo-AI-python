# 🎯 Adivina el Número — Workshop de Python, Cubo AI

Es un juego para la terminal escrito en Python, en el que la computadora piensa un número al azar y la persona intenta adivinarlo.

## 📌 Descripción

Al iniciar, el programa elige un número aleatorio dentro de un rango de 1 a 99. En cada intento, el jugador escribe un número y el juego indica si el número secreto es **mayor** o **menor**, hasta que lo adivina.

## 🎯 Objetivos de aprendizaje

- Usar ppythom para diseñar un juego en la terminal
- en este caso se usa el módulo `random` para generar números aleatorios
- Leer datos del usuario con `input()`
- Convertir tipos de datos (`int()`)
- Controlar el flujo con ciclos (`while`) y condicionales (`if / elif / else`)
- Ejecutar un programa de Python desde la terminal

## 🛠️ Tecnologías

- Python 3
- Terminal (PowerShell o VisualStudioCode)
- Git y GitHub

## ▶️ Cómo ejecutarlo

1. Asegúrate de tener Python instalado:
   ```bash
   python --version
   ```
2. Clona el repositorio:
   ```bash
   git clone [https://github.com/alcyruava-byte/Cubo-AI-python]
   cd Cubo-AI-python
   ```
3. Ejecuta el juego:
   ```bash
   python [import_ramdom.py]
   ```

## 🕹️ Cómo se juega

1. El programa elige un número secreto entre [1 y 99].
2. Escribe tu intento y presiona Enter.
3. El juego te dirá si el número es mayor o menor.
4. Sigue intentando hasta adivinar.
